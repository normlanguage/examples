# Norm examples

[简体中文](README.zh-CN.md)

Independent Norm application examples that use the released CLI and NAR packages without building or referencing compiler source code.

- [Single-file web application](micronaut-single-file/README.md)
- [Micronaut BBS](micronaut-bbs/README.md)
- [ORM](norm-orm/README.md)
- [Java interoperability](java-commons-lang/README.md)

Requires Norm 0.21.2 or later. Run `node scripts/verify.mjs` to verify the applications, or `node scripts/verify.mjs --native` to verify Native web and database behavior. Set `NORM_CLI` to select the compiler executable.
